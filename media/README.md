# media/
**Purpose:** small images used in the report or docs.
**What belongs here:** `media/waveforms/<module>/YYYYMMDD-desc.png`, `media/board/YYYYMMDD-desc.jpg`, `media/ui/YYYYMMDD-desc.png` — PNG/JPG under 1 MB.
**What does NOT belong here:** videos (→ link in `VIDEOS.md`), screenshots only needed for a PR (drag them into the PR instead).
